# AC Education · 靈活教務前端演示

## 啟動

```sh
npm run dev -- --host 127.0.0.1
npm run build
node --test tests/*.test.js
```

本項目僅為前端原型。React + Ant Design + Vite，全部資料儲存在此瀏覽器的 localStorage (`ac-flex-demo-v3`)。沒有真實登入、後端、付款、雲端儲存或對外訊息發送。右上角切換管理員、老師、家長；「演示與角色」可重設資料。日期以香港時間初始化。

## 整合取捨

- Counter 正式項目：學生預約與老師課堂關聯、老師科目及年級、可用時間、多人同行、管理員 / 老師 / 家長視角。
- Counter 原型演示：老師時間線、預約申請處理、按角色看學生和課堂。
- Python 帳務項目：Invoice / Receipt / Both、課堂日期和時段、時長、數量、單價、附加費、固定或百分比折扣、付款方式、發行人、單據預覽。
- kk 原版：保留 React / Ant Design 基礎，改為靈活排課。舊版 main.jsx 和樣式備份在 reference/。
- 不建立固定班級、招生漏斗、多校區、人事薪酬等大型機構流程。

Python 專案是帳務開單服務，並未實作課包扣減；本原型另加課時餘額和課消流水。未移植 Python 雲端冪等協議或 Google Drive / Sheets：原型的重複課消防護和待開單過濾只在本機資料內生效。

## 可走通的演示

1. 工作台「林浩然想連上三天」→ 安排老師李健 → 逐日確認可用 → 三天課堂一併進入課表。
2. 「陳梓晴調課」→ 新時間 / 老師 → 保留原課堂 ID 和調課操作記錄。
3. 老師端 → 考勤 → 出席 / 遲到 / 請假 / 缺席 → 完成課堂，記入流水。
4. 李卓軒按次付費 → 完成考勤 → 帳單與收款 → 從課堂開單 → 登記收款 → 預覽帳單及收據。
5. 課包學生 → 續購課包 → 只開 Invoice 時餘額不增加 → 登記收款後入帳；Receipt / Both 代表已收款，直接入帳。
6. 家長端固定示範陳太 / 陳梓晴 → 提出預約或調課 → 管理員處理後同一瀏覽器同步顯示。
7. 老師與可用時間 → 新增 / 編輯老師科目、年級、固定或指定日期時間 → 衝突時阻止安排。

## 暫定業務規則（需與機構確認）

- 通用課包，出席或遲到每堂扣 1，不隨時長改變；請假 / 缺席不扣。沒有罰扣、退款、課包到期或按小時計費；未開單課堂可由管理員更正考勤並退回原扣課，必須填寫原因。
- 課包可以先約課；餘額不足仍記錄出勤並留下待補扣，續購收款後按日期補扣。只有收款後新增課包餘額。
- 按次付費學生完成課堂後才開單，已開单課堂不再出現在待開單清單。其他單項收費為人工輸入，不自動影響課時。
- 所有收款是全額登記；不含分期或部分付款。以 HKD 計價，百分比折扣基於明細小計，不含附加費。
- 同一老師、學生、課室不能重疊；相鄰時間可安排。演示課室為 A / B，開放時段 10:00–21:00。
- 一次可安排最多 14 天 / 週，逐日換老師；本次選中的課堂全部檢查通過才儲存；多日需求可先排部分日期，未選日期繼續待安排。沒有自動假期日曆。
- 完成後不允許重複扣課或直接修改課堂；更正考勤會保留原流水和沖回記錄，已開單課堂禁止更正；取消未完成課堂釋放時段，沒有扣課。
- 三個角色只是演示資料篩選，不是真實的安全權限機制。

原型使用 6 名示範學生、3 名老師，真實目標規模 50–100 名學生；不以虛構數字假裝已接入真實資料。

## 業務場景自動演示（2026-09-30）

點右上角「場景演示」，選擇場景即自動打開頁面、填寫表單並提交。右側同步顯示講解、操作路徑和步驟，支援暫停、下一步、速度調整和重播。

原 11 個場景：連續三天、每週預約、兼職可用時間、衝突攔截、小組單人調課、點名扣課、考勤更正、續購課包、按次開單收款、新生建檔、家長預約。

每次演示使用獨立臨時資料，退出恢復原有資料及頁面；不寫入業務 localStorage。提交走實際表單與驗證，結果不符合預期時會停止播放。首次介紹建議順序：連續三天 → 點名扣課 → 續購十堂。

「操作手冊」包含功能完整度評估、各場景講解及未實作範圍。核心日常流程足以驗證需求；正式使用仍需後端、真實權限、備份及併發控制。部分付款、真實退款、課包到期及一鍵批量代課待確認需求後處理。已提供未收款作廢、誤收款撤銷及逐堂代課。

本次簡化：排課按天選老師並推薦可用老師；工作台數字可直接進入待辦；考勤預設只看待記錄；待開單課堂可直接帶入開單表單；錯誤考勤提供有原因、有流水的更正入口。

## 業務閉環改進（2026-10-08）

- 工作台集中待安排、待點名、待開單 / 收款和異常；過期需求提示重新確認，低課時入口直接篩選。
- 考勤與扣課解耦：零課時仍可點名，待補扣可追蹤；續購收款後自動補扣，不能重複執行。
- 老師可登記指定日期不能授課，受影響課堂不會刪除，工作台逐堂處理代課 / 改期；管理員可恢復時段。
- 改變家長原需求的方案需待確認或明確記錄已線下確認。待確認方案不佔位，同意時重新檢查衝突。
- 單人請假不改同堂其他學生；可建立另約待辦，安排後關閉。請假不扣課，不贈送補課額度。
- 未收款帳單可作廢並重新開單；誤登收款可撤銷，課包同步扣回。已使用且剩餘不足的課包不可直接撤銷，真實退款不在本原型範圍。
- 支援時間範圍需求與空檔推薦、逐日微調及部分日期先安排。
- 每堂保存計費方式和單價；修改課程價格或學生的新預約計費方式不追溯已有課堂。舊資料在第一次載入新版時按當時設定補上快照，無法還原此前已丟失的歷史報價。
- 收費只問收什麼費用及是否已收到款；折扣等放入更多設定。
- 新增週視圖、同系列「僅本次 / 本次及以後」調整，衝突時整組不儲存。舊版建立而未帶系列關聯的課堂仍逐堂調整。

演示面板共 17 個場景，新增 6 個異常跟進流程。資料仍只在瀏覽器本機，無真實通知、家長登入及權限隔離；確認方案可在演示角色中操作。
